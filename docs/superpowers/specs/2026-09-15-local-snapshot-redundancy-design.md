# 本地记录冗余与恢复设计

**状态：** 待评审
**日期：** 2026-09-15
**目标版本：** 0.1.2

## 背景

`history.db` 是本地历史的唯一真相来源。2026-09-15 观察到一份 1548288 字节的历史库中有 367 页整页为零，SQLCipher 判定其不是数据库，全部历史无法读取。单个文件损坏即导致全部历史丢失，这是当前架构最严重的单点故障。

## 目标

- 损坏或误删 `history.db` 后，客户端仍能恢复历史，最多丢失最近一个快照周期。
- 冗余覆盖全部本地记录：文本与图片元数据、加密图片对象，以及收藏文件束缓存。
- 快照目录默认位于同一磁盘的另一目录，并允许用户指定另一块磁盘的目录。
- 提供从远端重建历史的正式入口，覆盖整盘或整机损坏。
- 绝不在未通过完整性校验时把文件当作可用快照。

## 非目标

- 不实现逐条同步冗余，允许丢失最近一个快照周期，不做零丢失保证。
- 不做远端快照存储，远端只承载既有的加密事件流。
- 不改变现有隐私边界：快照同样是加密数据，不含明文。

## 已确认的产品决策

| 决策点 | 结论 |
| --- | --- |
| 丢失窗口 | 允许丢失最近一段时间 |
| 方案 | 快照冗余加自动回退 |
| 快照位置 | 默认同盘另一目录，可指定另一块磁盘 |
| 覆盖范围 | 全部本地记录，含图片对象与文件束缓存 |
| 远端恢复 | 本次一起实现 |

## 快照内容与布局

每次快照在配置的快照根目录下创建 `snapshot-<yyyyMMdd-HHmmss>` 目录，包含：

- `history.db`：仅在完整性校验通过后抓取的数据库副本
- `history.vault`：vault 标记
- `manifest.json`：格式版本、创建时间、客户端版本、条目计数、总字节数、对象清单与校验值
- `objects/`：本次快照引用的加密对象；同一卷上优先使用硬链接，跨卷时复制

文件束缓存单独占用空间上限，快照按同一规则处理：只保留被保留快照引用的文件，其余在裁剪时删除。

## 生命周期

1. 触发：自上次快照以来累计 500 条写入、距上次快照超过配置间隔（默认 30 分钟），或客户端正常退出时执行；三者先到先触发。
2. 前置校验：先对活动数据库执行解密打开与 `PRAGMA integrity_check`，未通过则跳过本次快照并记录类别，绝不为损坏数据库创建快照。
3. 抓取：复制数据库与标记，按清单补齐对象。
4. 后置校验：重新打开快照中的数据库并再次执行 `integrity_check`，逐个校验对象可解密；只有全部通过才写入 `verified` 标记，否则删除该快照目录。
5. 裁剪：仅保留最近 N 份已校验快照，并删除不再被任何保留快照引用的对象与缓存文件。

## 恢复流程

- 启动时活动数据库无法打开且状态为无法解密或损坏：按时间从新到旧扫描快照，选择第一个校验通过且能打开的副本，把损坏的当前库重命名为 `history.db.corrupt-<时间戳>` 备份，再恢复快照内容并继续启动，同时在面板状态栏说明已从快照恢复。
- 没有任何可用快照时，保持现有行为：备份损坏库并重建空库。
- 快照恢复同样覆盖对象与文件束缓存。

## 远端恢复

设置页提供「从远端恢复历史」：确认后备份当前库，重建空库，再执行一次完整的远端拉取与合并，报告拉取与合并计数。该操作要求已配置远端与凭据，且只在用户显式确认后执行。

## 设置

`ClientSettings` 新增非敏感字段：`SnapshotDirectory`（可空，默认空表示使用默认目录）、`SnapshotIntervalMinutes`（默认 30）、`SnapshotKeep`（默认 3）。校验规则：目录必须为绝对路径且不得位于数据目录内部；间隔为 1 到 1440 分钟；保留份数为 1 到 10。默认快照目录为 `%LOCALAPPDATA%\Clipboard\snapshots`。

## 失败分类与日志

新增状态码 `SnapshotFailed = 15` 与 `SnapshotRestoreFailed = 16`。日志只记录类别、快照计数与布尔结果，不记录路径、密钥或历史内容。

## 测试策略

- Rust：快照创建与校验、拒绝为损坏库创建快照、对象与缓存进入快照、裁剪保留份数与对象回收、损坏快照被跳过并回退到更早副本、快照目录校验。
- 客户端：设置校验、启动回退选择最新可用快照、远端恢复的编排顺序（备份、重建、拉取）。
- 端到端手工验证：删除活动数据库后启动，确认历史与图片从快照恢复。

## 验收标准

- 损坏或删除 `history.db` 后启动客户端，历史与图片从最近一次通过校验的快照恢复，最多丢失一个快照周期。
- 未通过校验的快照不会被使用。
- 快照可写入另一块磁盘的目录；目录非法时给出明确提示并保持快照功能关闭。
- 裁剪后不会遗留未被引用的对象或缓存文件。
- 配置远端后可从远端重建历史，并报告拉取与合并计数。
