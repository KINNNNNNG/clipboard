# 文件历史卡片与来源应用名称设计

## 目标

完成阶段 3 的 Task 4：文件束记录不再把完整路径当作普通文本显示，而是使用 Windows 原生风格的 Fluent 文件/文件夹图标、代表名称和条目数量；来源应用同时保留稳定的 exe 标识与用户可读的软件名称。

## 当前问题

- Core 的 `SearchItem.preview` 对文件束直接拼接所有完整路径，WinUI 的通用模板无条件显示该字段，因此列表展示路径文本。
- `SourceApplicationResolver` 只返回 `ProcessName + ".exe"`，领域模型与数据库也只有 `source_app`，界面没有产品展示名称可用。
- 文件筛选菜单只有文本和图片，虽然 Core 已支持 `file_bundle` 类型筛选，但界面没有入口。

## 文件束搜索摘要

Core 的文件搜索继续使用完整本机路径作为内部可搜索字段，但搜索响应不返回完整路径。`SearchItem` 为文件束增加以下可选字段：

- `file_count`：条目总数。
- `representative_name`：第一个条目的末级文件名或文件夹名。
- `representative_kind`：`file` 或 `directory`。

`representative_name` 取规范化路径最后一个非空段；无法取得时按类型回退为“文件”或“文件夹”。文件束的通用 `preview` 只返回该名称，兼容旧客户端且避免列表 DTO 暴露完整路径。文本和图片响应保持不变。

## 文件卡片界面

- 单个文件：Fluent 文件图标、文件名。
- 单个文件夹：Fluent 文件夹图标、文件夹名。
- 多个条目：使用第一个条目的类型作为代表图标，第一行显示代表名称，第二行显示 `共 N 项`。
- 元数据行继续显示来源应用、复制时间、收藏和更多操作。
- 文件卡不加载 Shell 关联图标，不引入图标缓存、COM Shell API 或路径 I/O。
- 筛选浮层增加“文件”复选框，并把选中状态传为 `file_bundle`。

文件名和路径搜索仍由 Rust Core 完成。正则与子串搜索行为不变。

## 来源应用元数据

领域模型保留 `source_app` 作为稳定标识，例如 `explorer.exe`，并增加可选的 `source_app_display_name`。数据库使用新增可空列保存展示名称；旧数据库迁移后该列为 `NULL`，无需重写历史。

Windows 捕获时，来源解析器返回：

- `Identifier`：规范化为带 `.exe` 后缀的进程名。
- `DisplayName`：优先读取可执行文件版本信息的 `FileDescription`，其次读取 `ProductName`，最后使用系统应用映射或移除 `.exe` 的进程名。

`explorer.exe`、`notepad.exe` 和 `mspaint.exe` 使用稳定的本地化名称映射。所有名称去除首尾空白并限制为 128 个 UTF-16 字符，不把可执行文件路径写入日志、DTO 或错误信息。

界面只显示 `source_app_display_name`。来源筛选在 Core 中对稳定标识、展示名称和去掉 `.exe` 的标识执行大小写不敏感的精确匹配，既兼容现有筛选值，也允许用户按可见名称筛选。旧记录或无法解析的程序在 ViewModel 中使用安全降级名称，因此现有历史也不会继续直接显示 `.exe`。

## 路径失效状态

搜索刷新不主动访问每个文件路径，避免大量记录或 UNC 路径阻塞即时搜索。粘贴时沿用现有逐项验证：任何文件或文件夹不可访问时，不写系统剪贴板、不隐藏面板、不恢复目标窗口，也不发送 `Ctrl+V`。

`PasteCoordinator` 返回明确的 `SourceUnavailable` 结果，ViewModel 将当前卡片标记为“原路径不可用”。该状态只属于当前客户端会话，不写数据库；删除和取消收藏仍可用。收藏缓存恢复将在 Task 5 实现。

## 兼容性与边界

- 新的 JSON 字段均为可选字段，旧 C ABI 请求和旧数据库继续可读。
- 文件束仍为 `local_only`，路径、代表名称、条数和可用状态不得进入同步 outbox。
- 文本、图片捕获、图片预览、Win+V、点击外部隐藏和立即粘贴流程不改变。
- 本阶段不实现真实文件类型图标、文件缩略图、收藏缓存或跨设备文件同步。

## 测试

- Rust 测试验证文件束响应只包含代表名称和数量，不在 `preview` 暴露完整路径，同时完整路径搜索仍命中。
- 存储迁移测试验证旧数据库升级后展示名称为空且记录可读。
- C# 测试验证来源解析优先级、旧 exe 名降级、文件卡摘要和 Fluent 图标选择。
- ViewModel/XAML 测试验证文件筛选传递 `file_bundle`，文件卡隐藏通用路径预览。
- 粘贴测试验证路径失效返回 `SourceUnavailable`，且不隐藏窗口、不恢复焦点、不发送输入。
- 完整 Windows 测试、Rust workspace 测试和 x64 构建必须通过。
