# Clipboard 0.1.3

本版本修复剪贴板面板关闭时偶发的焦点丢失与抢占问题。

## 修复

- 先恢复打开面板前的应用窗口，再隐藏面板，提升立即粘贴时的前台恢复稳定性。
- `Esc` 关闭、右键复制和立即粘贴统一使用来源窗口恢复流程。
- 面板已因失焦关闭时，后台完成的操作保留剪贴板内容，不再把焦点拉回旧窗口。
- 关闭操作等待焦点恢复期间重新打开面板时，旧关闭任务不会隐藏新面板。
- 立即粘贴等待焦点恢复期间重新打开面板时，旧任务不会发送 Ctrl+V。

## 安装

安装包文件名：`Clipboard-Setup-v0.1.3.exe`。覆盖安装会保留 `%LOCALAPPDATA%\Clipboard` 下的历史、密钥和设置。
