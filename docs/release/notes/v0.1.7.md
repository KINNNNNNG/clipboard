# Clipboard 0.1.7

本版本重构保险库身份与加密边界，并切换到新的本地存储格式。

## 变更

- 主密钥独立负责加解密，Vault ID 只用于标记保险库身份和防止数据误混。
- 本地历史使用 `data-v2` 目录，快照使用独立的 `v2` 子目录。旧数据目录保持原样，不会自动删除或覆盖。
- 新版本从空历史开始；升级后需要重新积累历史记录。
- 同步协议升级到 v2，参与同步的设备需要升级到兼容版本。

## 修复

- 并发首次启动使用同一份密钥和 Vault ID，不互相覆盖。
- 密钥、Vault ID 或数据库标记不一致，以及数据库无法解密或损坏时，停止自动恢复、空库重建和写入，保留现场数据。
- 修复本地打包使用相对输出目录时的资源路径错误。

## 安装

安装包文件名：`Clipboard-Setup-v0.1.7.exe`。旧版本的 `%LOCALAPPDATA%\Clipboard\data`、`vault.key`、设置和备份不会被新版本删除。
